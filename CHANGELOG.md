# Changelog

## [1.0.0] - 2026-08-25

### Added
- ✨ Initial release of Electronic Radio
- 🎵 200+ electronic music radio stations
- 🖥️ Desktop application (Windows, macOS, Linux)
- 📱 Android mobile application
- 🎧 Real-time audio streaming
- 💚 Favorites management system
- 🔍 Advanced search and filtering
- 🌍 Station filtering by genre and country
- 🎛️ Volume and quality controls
- 📊 Stream statistics (listeners, uptime, bitrate)
- 🌓 Dark/Light theme support
- 💾 Recently played history (50 stations)
- ⚙️ Settings panel with audio quality selection
- 🎨 Modern UI with smooth animations
- 📦 Cross-platform installers

### Technical
- React 18 with functional components and hooks
- Electron for desktop application
- Capacitor for mobile/Android
- Zustand for state management
- Tailwind CSS for styling
- Framer Motion for animations
- Express.js backend API
- Node.js runtime environment

### Database
- 150+ radio stations included (expandable)
- Multiple genres (House, Techno, Trance, Drum & Bass, etc.)
- Stations from 50+ countries
- Quality info and listener statistics

- Installation guide (INSTALLATION.md)
